# Analog Clock

A simple analog clock built with vanilla JavaScript, HTML, and CSS. The clock hands update in real time using `setInterval`, the `Date` object, and CSS `transform: rotate()`.

## Features
- Real-time hour, minute, and second hand movement
- Built using pure JavaScript — no libraries or frameworks
- Smooth CSS-based rotation for each hand

## Tech Used
- HTML
- CSS
- JavaScript

## How to Run
1. Clone this repository
2. Open `index.html` in your browser
   
   or

3. Use the Live Server extension in VS Code for real-time preview

## What I Learned
- Working with the JavaScript `Date` object (`getHours()`, `getMinutes()`, `getSeconds()`)
- Using `setInterval()` to update the UI every second
- Applying CSS `transform: rotate()` dynamically via JavaScript
